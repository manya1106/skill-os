# Skill OS

A comprehensive platform designed to make student learning easier by aggregating pending lectures from multiple applications, rewarding task completion, and conducting confidence-building tests.

## 📋 Overview

**Skill OS** is an innovative educational platform that streamlines the student learning experience. It consolidates lectures from various applications into one centralized hub, gamifies learning through reward mechanisms, and provides assessment tools to boost student confidence.

### Key Features

- **📚 Unified Lecture Dashboard**: Aggregate all pending lectures from different applications in one place
- **🎮 Gamified Learning**: Earn rewards and achievements for completing tasks and courses
- **📊 Assessment Tools**: Conduct tests to evaluate understanding and build confidence
- **🎯 Task Management**: Track pending assignments and lectures in real-time
- **📱 Browser Extension**: Quick access to lectures through a convenient browser extension

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher recommended)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/manya1106/skill-os.git
   cd skill-os
   ```

2. **Install frontend dependencies**
   ```bash
   cd frontend
   npm install
   cd ..
   ```

3. **Install backend dependencies** (if applicable)
   ```bash
   cd backend
   npm install
   cd ..
   ```

### Development

#### Running the Frontend

```bash
cd frontend
npm run dev
```

The development server will start at `http://localhost:5173` (Vite default).

#### Building for Production

```bash
cd frontend
npm run build
npm run preview
```

#### Linting

```bash
cd frontend
npm run lint
```
